02 / REFERENCE

What’s in the data

FIELD GUIDE

The snapshot targets 2,500 leading assets by market cap by default. Refreshes are scheduled for minute 09 of each hour (UTC) and may be delayed. Rankings can change between requests, so the order is approximate.

FieldMeaning
idCoinGecko asset ID
market_cap_rankMarket-cap rank
name, symbolAsset name and ticker
current_priceUSD price
market_capUSD market capitalization
fully_diluted_valuationUSD fully diluted valuation
price_change_percentage_24hRolling 24-hour price change (%)
last_updatedSource update time
imageCoinGecko image URL
total_volume24-hour trading volume (USD)
athAll-time high price (USD)
ath_dateWhen the all-time high occurred
ath_change_percentagePercentage change from the all-time high (usually negative)

Missing values are blank in CSV and null in JSON. JSON includes the snapshot completion time. Data is not investment advice.
